# A small excercise in Android

## NOTE: The code is outdated, as the preferred method for UI building is now Jetpack Compose. Dependencies in this project have known vulnerabilities and no update is planned.

This is a small application built on the Dice Roller codelab from Android tutorials. It allows you to either roll the dice (6-sided) or to toss a coin.

Main purpose behind this repo was poking around Espresso tests a bit.
